# API de Cursos
API para gerenciamento de **professores** e **cursos**

## Tecnologias
- Javascript
- Node JS
- Mysql
- Expresss

## Endpoints
- `POST /professores` - Cria um professor
- `GET /professores` - Lista profesores
- `POST /cursos` - Cria cursos
- `GET /cursos` - Lista cursos
- `DELETE /cursos/id` - Deleta curso por id
